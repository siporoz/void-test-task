# Состав проекта

Тестовое задание для VOID: интерфейс выбора услуг и расчёта стоимости проекта.
Стек: React, TypeScript, Vite. Node.js 24, npm.

## Запуск

```sh
nvm use
npm install
npm run dev
```

## Проверки

```sh
npm run check
```

Команда запускает линтер, проверку форматирования и сборку с проверкой типов.

- `npm run lint` — проверка TypeScript и React через Oxlint, включая правила хуков и зависимости эффектов.
- `npm run lint:fix` — автоматическое исправление поддерживаемых линтером проблем.
- `npm run format` — форматирование файлов через Prettier.
- `npm run format:check` — проверка форматирования без изменения файлов.
- `npm run build` — проверка типов TypeScript и production-сборка.

Prettier использует два пробела, одинарные кавычки и стиль без точек с запятой.
